Пошаговое руководство по запуску локально и на бесплатном хостинге

1. Игра работает прямо сейчас!

В этом окне уже подключена облачная база данных реального времени (Firebase Firestore) и 3D-движок Three.js. Просто введите одинаковый ID Комнаты (например, ARENA-1), чтобы видеть других игроков, или включите ИИ-ботов для одиночной тренировки.

2. Бесплатный хостинг (GitHub Pages / Netlify Drop / Vercel)

Так как вся игра собрана в одном файле index.html, вам не нужен платный VPS-сервер:

  1. Сохраните этот код в файл с именем index.html на компьютере.
  2. Самый быстрый способ (за 30 секунд): Зайдите на app.netlify.com/drop и просто перетащите папку с файлом index.html в окно браузера — вы сразу получите публичную HTTPS-ссылку для друзей!
  3. Через GitHub Pages: Создайте бесплатный репозиторий на GitHub, загрузите туда index.html и включите Settings → Pages → Deploy from branch (main).

3. Свой бесплатный сервер синхронизации Firebase (для внешнего хостинга)

Если вы выкладываете файл на свой GitHub Pages или запускаете локально на ПК, подключите свой бесплатный проект Firebase (тариф Spark — 100% бесплатный):

  1. Зайдите в console.firebase.google.com → Создать проект.
  2. Включите Authentication → Sign-in method → Анонимный вход (Anonymous).
  3. Включите Firestore Database (в тестовом режиме Start in test mode).
