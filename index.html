КАК ИГРАТЬ ПО СЕТИ НА GITHUB PAGES

Мультиплеер теперь работает автоматически без настройки!

1. Работает на GitHub Pages «из коробки» (Zero-Config)!

В этот файл уже встроен автоматический глобальный сетевой движок WebSocket Relay (WSS MQTT + BroadcastChannel). Когда вы загружаете этот index.html на свой GitHub Pages (например, mqhoodvac.github.io/shutertopai/), игра автоматически подключается к публичному WSS-ретранслятору за 1 секунду.

Чтобы играть с другом: просто откройте вашу ссылку GitHub Pages на двух компьютерах, укажите одинаковый ID Комнаты (например, ARENA-1) и нажмите «ВСТУПИТЬ В БОЙ»!

2. Как обновить файл на вашем GitHub Pages

  1. Скопируйте обновленный код этого файла index.html.
  2. Откройте ваш репозиторий на GitHub (например, MQHoodVAC/shutertopai) → нажмите на файл index.html → нажмите иконку карандаша (Edit this file).
  3. Вставьте новый код, нажмите Commit changes и подождите 30–60 секунд, затем обновите страницу игры сочетанием клавиш Ctrl + F5.
